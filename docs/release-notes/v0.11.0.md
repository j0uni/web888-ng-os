**Decoders in the browser:** each listener's page now decodes CW,
RTTY/NAVTEX, DSC, PSK, HF fax, SSTV, HFDL, JS8 and the time stations,
names the mode of the signal in the passband, and records IQ. AM has
AGC speeds, and 24 kS/s audio takes the passband to ±10 kHz. With
web888d v0.14.0. Test images, for owners who have their Web-888 at hand.

**Updating from v0.9.0 or later:** the admin page's **Update** tab
offers v0.11.0 (it looks once a day, or press **Look for a release**):
**Install**, then **Reboot now**. The unit keeps its settings and goes
back to the previous system by itself if the new one doesn't come up
([docs/updates.md](https://github.com/jeskko/web888-ng-os/blob/v0.11.0/docs/updates.md)).

**From v0.3.0 to v0.8.0** (SSH, with an `ssh_key` in `web888.txt`):

```sh
rauc install https://github.com/jeskko/web888-ng-os/releases/download/v0.11.0/web888-ng-v0.11.0.raucb
reboot
```

Units on v0.1.0 or v0.2.0 write this card image instead (keep a copy of
`web888.txt`).

## New since v0.10.0

**web888d v0.14.0**
([its notes](https://github.com/jeskko/web888-ng/releases/tag/v0.14.0)):

* **Decoders** under the page's **Decoders** button, each in a panel
  beside the waterfall. They run in the listener's browser, so the unit
  only sends the audio:
  * CW, with a neural decoder for weak and fading signals;
  * RTTY with the settings worked out from the signal, NAVTEX, DSC
    (ship and coast station calls);
  * PSK31/63/125;
  * HF fax and SSTV pictures;
  * HFDL (aircraft data link: positions on the map);
  * JS8;
  * time stations (DCF77, MSF, WWVB, JJY, WWV/WWVH).
* A **signal identifier** that names the mode of the signal in the
  passband and opens its decoder.
* **Wide skimming:** the CW and RTTY panels can skim a whole 40 kHz
  channelizer bin at once.
* **Rec IQ:** records the 60 kHz around the dial for up to 5 minutes and
  saves it in the browser.
* **AGC speed in AM** (fast, medium, slow): medium, the default, holds
  the gain through quick fades instead of raising the noise in each one.
* **24 kS/s audio** beside the passband presets, for broadcast AM and
  NBFM up to ±10 kHz. 12 kS/s stays the default.

Nothing else changes: the same kernel, packages and bitstreams as
v0.10.0.

## Tested

## Known limits

* VHF (`band = vhf`) still needs testing against real signals or a signal
  generator (see v0.7.0's notes).
* The Update tab has installed updates in the emulator, not yet on a
  board; SSH (above) remains the way if it fails.
* The boot loader update (v0.10.0) has run in the emulator only. Writing
  it is optional.
* Kiwi clients get levels in dBFS unless `[kiwi] smeter_offset_db` is
  set: the dBm calibration hasn't been measured yet.
* Safe mode has run in the emulator, not yet on a board.
* Assumes the usual 24.576 MHz reference for the ADC clock.
* Over plain HTTP the browser plays audio with about a quarter second more
  delay. The status bar links to the HTTPS address (the browser warns once
  about the unit's own certificate).
* No Wi-Fi since v0.9.1.
* The stock firmware's extensions and the Kiwi browser UI are not
  included.
