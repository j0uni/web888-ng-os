**The page in Finnish, Swedish and German:** web888d v0.16.0 shows the
receiver and admin pages in Suomi, Svenska and Deutsch (the browser's
language, or Config → Language), gathers the listener's own settings in
a Config box, and makes the ADC overload log clearer. Test images, for
owners who have their Web-888 at hand.

**Updating from v0.9.0 or later:** the admin page's **Update** tab
offers v0.13.0 (it looks once a day, or press **Look for a release**):
**Install**, then **Reboot now**. The unit keeps its settings and goes
back to the previous system by itself if the new one doesn't come up
([docs/updates.md](https://github.com/jeskko/web888-ng-os/blob/v0.13.0/docs/updates.md)).

**From v0.3.0 to v0.8.0** (SSH, with an `ssh_key` in `web888.txt`):

```sh
rauc install https://github.com/jeskko/web888-ng-os/releases/download/v0.13.0/web888-ng-v0.13.0.raucb
reboot
```

Units on v0.1.0 or v0.2.0 write this card image instead (keep a copy of
`web888.txt`).

## New since v0.12.0

**web888d v0.16.0**
([its notes](https://github.com/jeskko/web888-ng/releases/tag/v0.16.0)):

* **Languages:** Suomi, Svenska and Deutsch, with the radio terms
  reviewed. The translations are gettext PO files in web888-ng's
  `ui/po/`, and its `ui/po/README.md` tells how to correct one or add
  a language.
* **Config box** (Config in the header): callsign or nickname, sharing,
  the data saver, the waterfall's colours and time marks, and the
  labels, in one place.
* **ADC overload log:** the real peak of each event, short switching
  spikes called "brief" instead of blamed on the strongest station.
* **Info** is in the status bar beside keys and admin.

The image installs the UI's new `i18n/` folder. The kernel, packages and
bitstreams are the same as in v0.12.0.

## Tested

In the emulator (web888-ng-hw `emu/tests/`), on this release's build:
* the image's boot through the boot ROM, both slots, `web888.txt` and
  safe mode (`sd-image.sh`);
* **the update from the published v0.12.0 image to this release's
  bundle** (`ota.sh`), with a power cut mid-install and a bad update
  rolled back.

On a Web-888 (the developer's remote unit, its own image chain-loaded):
web888d v0.16.0's additions with the channelizer. On that unit, the
CPU work in v0.15.0 showed in a day's metrics: in the busy mornings the
skimmers used to drop 2-9 % of their decoding slots and now drop none.

## Known limits

* VHF (`band = vhf`) still needs testing against real signals or a signal
  generator (see v0.7.0's notes).
* The Update tab has installed updates in the emulator, not yet on a
  board; SSH (above) remains the way if it fails.
* The boot loader update (v0.10.0) has run in the emulator only. Writing
  it is optional.
* Kiwi clients get levels in dBFS unless `[kiwi] smeter_offset_db` is
  set: the dBm calibration hasn't been measured yet.
* Safe mode has run in the emulator, not yet on a board.
* Assumes the usual 24.576 MHz reference for the ADC clock.
* Over plain HTTP the browser plays audio with about a quarter second more
  delay. The status bar links to the HTTPS address (the browser warns once
  about the unit's own certificate).
* No Wi-Fi since v0.9.1.
* The stock firmware's extensions and the Kiwi browser UI are not
  included.
